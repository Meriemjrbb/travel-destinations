# Travel Destinations — TP4 React Hooks

## Lancer le projet
```bash
npm install
npm run dev
```
Ouvrir ensuite http://localhost:5173

## Contenu
- `useState` : liste des destinations, recherche, filtre par note, affichage de la modal, formulaire
- Recherche par titre + filtre par note (utilisables ensemble)
- Ajout d'une destination via une `react-bootstrap` Modal avec validation
- Notes affichées avec `react-simple-star-rating`
